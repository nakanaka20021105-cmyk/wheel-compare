# CarCalc Works

**クルマの計算を、ひとつの場所で。**

## 概要

CarCalc Works は、クルマに関するさまざまな計算をブラウザだけで手軽に行えるようにすることを目指した Web サイトです。

最初のツールとして、現在のホイール・タイヤと交換候補を比較する「**ホイール・タイヤサイズ比較**」を公開しています。

- 計算はすべてブラウザ内で行い、入力した値を外部へ送信・保存しません。
- 計算結果は公称サイズなどにもとづく理論上の参考値です。実際の装着可否や安全性、車検・保安基準への適合を保証するものではありません。

## 主な機能（Ver.1.0）

### 計算・比較

- 現在と交換候補のホイール・タイヤサイズ比較
- ホイール外側端・内側端の位置変化
- タイヤ側面位置の変化
- タイヤ外径・外径差率
- 最低地上高の理論上の変化
- タイヤ外径変更による理論上の速度差
- 外側・内側クリアランスの任意入力と、交換後の残量の推定
- 断面図による現在と交換候補の比較

### 表示・使いやすさ

- スマートフォン・PC 対応

- ライトモード・ダークモード
- 初めての方向けの説明「はじめての方へ」（このツールについて／サイズ表記の読み方／基本的な使い方／クリアランスの測り方）
- 「ご利用上の注意・免責事項」

### サイト

- CarCalc Works のブランド表示

### ローカルでの確認方法

アプリ本体は `wheel-compare/` フォルダにあります（HTML・CSS・JavaScript のみで、ビルドは不要です）。

テストの実行（Node.js が必要です）:

```sh
cd wheel-compare
npm test
```

ブラウザで開く場合は、JavaScript モジュールを読み込むため、ローカルサーバー経由で開いてください（例）:

```sh
python -m http.server 8080 --directory wheel-compare
```

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy-pages.yml`）が `wheel-compare/` フォルダを GitHub Pages へ公開します。
